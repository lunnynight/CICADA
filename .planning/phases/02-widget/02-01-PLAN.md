**Riverpod override pattern for both files:**
The `setupStateProvider` is generated by `@riverpod` annotation. To override it in tests, create a fake Notifier class:

```dart
class FakeSetupState extends SetupState {
  final SetupStateData _initialState;
  FakeSetupState(this._initialState);
  
  @override
  SetupStateData build() => _initialState;
}
```

Then wrap widget in:
```dart
ProviderScope(
  overrides: [
    setupStateProvider.overrideWith(() => FakeSetupState(testState)),
  ],
  child: MaterialApp(home: Scaffold(body: WidgetUnderTest())),
)
```
