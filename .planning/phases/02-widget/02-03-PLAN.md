**Step 1: Create integration_test/app_test.dart**

Create a Patrol-based integration test file. The key challenge is that CicadaApp's HomePage calls `InstallerService.isGatewayRunning()` via Timer, which may throw in test. Handle this gracefully.

**Important Patrol API notes:**
- Patrol 3.x uses `patrolTest` function (not `patrolWidgetTest`)
- The callback receives `PatrolIntegrationTester $` (not `PatrolTester`)
- Use `$.pumpWidgetAndSettle()` to pump and wait for animations
- If `pumpWidgetAndSettle` times out due to Timer.periodic or unresolved futures, use `$.pumpWidget()` followed by `$.pump(Duration(...))` instead
- Access standard WidgetTester via `$.tester`

```dart
import 'package:flutter_test/flutter_test.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:patrol/patrol.dart';
import 'package:cicada/main.dart';

void main() {
  patrolTest(
    'app smoke test - launches and renders CICADA title',
    ($) async {
      await $.pumpWidget(
        const ProviderScope(child: CicadaApp()),
      );
      // Pump a few frames to let initial build complete
      await $.pump(const Duration(milliseconds: 500));
      
      // Verify app title renders
      expect(find.text('CICADA'), findsOneWidget);
    },
  );

  patrolTest(
    'app smoke test - shows navigation structure',
    ($) async {
      await $.pumpWidget(
        const ProviderScope(child: CicadaApp()),
      );
      await $.pump(const Duration(milliseconds: 500));
      
      // Verify at least one navigation item is visible
      // On wide screens: sidebar with nav items
      // On narrow screens: bottom navigation bar
      final hasSidebar = find.text('仪表盘').evaluate().isNotEmpty;
      final hasBottomNav = find.byType(NavigationBar).evaluate().isNotEmpty;
      expect(hasSidebar || hasBottomNav, isTrue);
    },
  );
}
```

Run `flutter test integration_test/app_test.dart` to verify the framework is configured correctly. This runs integration tests in the Flutter test runner (not on a device), which is sufficient for D-03 (framework-ready verification).

Note: Full Patrol native features (like `$.native`) require a real device/emulator. The smoke test here uses only the Flutter-level Patrol API which works in `flutter test` mode. Per D-05, this is CI-friendly.

If `patrolTest` is not available or has import issues, fall back to standard `testWidgets` with a comment explaining that Patrol native features require device testing:
```dart
import 'package:flutter_test/flutter_test.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:cicada/main.dart';

void main() {
  // Patrol framework is configured (pubspec.yaml: patrol ^3.13.1)
  // Native Patrol features ($.native) require device/emulator execution
  // These smoke tests verify app launches correctly using flutter_test runner
  
  testWidgets('app smoke test - launches and renders', (tester) async {
    await tester.pumpWidget(const ProviderScope(child: CicadaApp()));
    await tester.pump(const Duration(milliseconds: 500));
    expect(find.text('CICADA'), findsOneWidget);
  });
}
```
